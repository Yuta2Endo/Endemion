# ADS INTEGRATION REPORT — Яндекс.РСЯ (Автоплейсмент) на главной

## Summary

Рекламный блок Яндекс.РСЯ добавлен на главную страницу сайта: между блоком «Избранный проект» и каталогом «Наши игры».
Позиция задаёт сайт, а не алгоритм Яндекса: блок ставится в отведённый слот, который отмечает сервер.

Кампания: Яндекс.Автоплейсмент, page-id `20404024`.

---

## How it works

1. **Сервер** (`functions/_lib/ads.js`) отдаёт на главной слот для рекламы:
   `<div class="ads-slot" id="yandex-ads-home" data-ads-slot data-ads-page-id="20404024">`.
   Слот появляется только если в настройках окружения задан `YANDEX_ADS_PAGE_ID` (только цифры).
2. **Согласие** (`public/assets/app.js`): реклама показывается только после согласия посетителя на cookie —
   вместе с Яндекс Метрикой, поэтому вопрос в подвале один на двоих. При отказе cookie Яндекса удаляются,
   страница перезагружается без рекламы и Метрики.
3. **Скрипт** (`public/assets/ads.js`):
   - грузит контекст Яндекса (`https://yandex.ru/ads/system/context.js`) — в нём менеджер рекламы;
   - спрашивает у Яндекса блоки кампании (`https://an.yandex.ru/auto_placement/?page-id=…`, тот же адрес,
     что использует штатный загрузчик Яндекса);
   - выбирает блок по порядку предпочтения: `afterContentAd` → `inArticleAds` → `inLayoutAds` →
     `desktopFloorAd` / `mobileFloorAd` → `topAd` и рисует его в слот через `Ya.Context.AdvManager.render()`.
4. **Запасной путь**: если блок поставить не удалось (кампания не запущена, нет подходящего блока),
   подключается штатный загрузчик Яндекса (`ap-loader.js`) — он расставит блоки по правилам кампании сам.
   Пустое место при этом убирается, чтобы на странице не оставалось дыры.

## Configuration

```
YANDEX_ADS_PAGE_ID=20404024
```

Пустое значение — рекламы на сайте нет: слот не выводится, вопрос про cookie говорит только о статистике.

## Verification

- `npm test` — 176 тестов, включая новый тест главной (место блока между избранным проектом и каталогом игр).
- `npm run lint` — без ошибок.
- `npx playwright test tests/e2e/ads.spec.mjs` — 10 тестов (chromium, firefox, webkit, android, iphone):
  без согласия запросов к Яндексу нет; после согласия блок появляется между избранным проектом и каталогом игр,
  выбор сохраняется после перезагрузки.

## Notes

- **Кампания должна быть запущена.** Пока номер страницы не проходит проверку в кабинете, Яндекс отдаёт
  404 на запрос блоков и реклама не показывается (в консоли браузера: «Яндекс не отдал блоки кампании»).
- **Показ требует согласия на cookie.** Пока согласия нет, реклама и Метрика не грузятся.
- **Разметка проверена на всех браузерах**, но реальные объявления Яндекса пока показать нельзя:
  кампания ещё не активна. После запуска кампании стоит открыть главную, разрешить cookie и убедиться,
  что блок появился в нужном месте.
- Слот можно поставить на другие страницы: `adsBlock(env)` в `functions/_lib/ads.js`.
