## 1. Recommended homepage structure

На основе аудита Stage 01 и визуального направления (premium dark, минимализм, фиолетово-синие акценты, сильная типографика, просторная вёрстка):

1. **Header and navigation** — существующая шапка (логотип, разделы, поиск, профиль, уведомления, язык, меню). Сохранить, возможно轻微 уточнить отступы.
2. **Hero section** — крупный заголовок (Unbounded, display-1), субтит lead, две CTA-кнопки (Игры / Сообщество), фон с размытой обложкой featured game и мягким градиентным свечением. Заменить текущий сборный герой на цельный презентационный блок.
3. **Endemion introduction** — короткое описание студии ("Что мы делаем"), 3–4 преимущества/направления (игры, форум, devlog, Endemion ID) в минималистичных карточках.
4. **Featured projects** — карточка главной игры (Endemion Life) + сетка 남은 игр из каталога (использовать существующий `gameCard`).
5. **Ecosystem presentation** — ссылки на Endemion Life, Community (форум), Devlog, Endemion ID с иконками и краткими описаниями (без выдуманной статистики).
6. **Updates or development activity** — последние публикации из `/studio` (devlog/news), используя существующий `postCard`.
7. **Community links** — ссылка на форум и на профили, без выдуманных показателей активности.
8. **Footer** — существующий подвал (о студии, разделы, проекты, документы), сохранить.

**Важно:** не изобретать продукты, функции, статистику или анонсы. Использовать только реальные данные из базы (игры, публикации, настройки сайта).

## 2. Detailed implementation plan

### Шаг 1 — Подготовка (1–2 дня)
- Проверить `functions/studio.js` (`home`) — текущая структура секций уже близка к целевой (hero, featured, games, community, dev, now, upcoming).

### Шаг 3 — Реализация главной (3–5 дней)
- Переписать тело `home.onRequestGet` в `functions/studio.js` по новой структуре.
- Серверный рендеринг HTML (SEO), данные подгружаются из базы (игры, посты, настройки).
- Сохранить существующие маршруты, мета-теги, Open Graph, structured data (Organization).

### Шаг 4 — Проверка (1–2 дня)
- `npm run lint` — нет новых ошибок в `functions/` и `public/`.
- `npm test` — все применимые тесты проходят, тест главной обновлён под новый контент.
- Ручное bestätление главной на десктопе и мобильном.
- Проверка консоли браузера на ошибки.

## 4. Visual direction

- Тёмный premium фон (`--bg: #080a10`).
- Фиолетово-синие акценты (`--primary: #8b5cf6`, `--secondary: #6366f1`, `--highlight: #22d3ee`).
- Типографика: Unbounded для заголовков, Manrope для текста.
- Мягкие радиальные градиенты на фоне (как уже в `body::before` и `studio-hero-bg`), без неона.
- Субтле анимация Appear (`@keyframes rise`) при загрузке.
- Adaptive: контейнер 1240px, стек колонок на <=900px, одна колонка на <=680px.

**Избегать:** неон, избыточные градиенты, стеклоэффект, перегруженные карточки, декоративные элементы без функции, AI-генерированный контент.
