## 6. Proposed Stage 05: Game Ratings & Reviews

**Цель:** Добавить систему оценок и отзывов пользователей к играм, повышая ценность каталога как источника информации.

### Компоненты:
- Таблица `game_reviews(user_id, game_id, score 1-10, body, spoiler, created_at, updated_at, hidden_at)`
- API: `GET /api/games/:slug/reviews`, `POST /api/games/:slug/reviews`, `PATCH /api/games/:reviews/:id`, `DELETE /api/games/:reviews/:id`
- UI: форма оценки на странице игры, список отзывов, средний рейтинг в hero/мета-блоке
- Локализация RU/EN

### Риски:
| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Регрессия страниц игр | Средняя | Средняя | Добавлять новые CSS-классы, не удалять старые |
| Выдуманные оценки | Низкая | Высокая | Только реальные оценки от пользователей |

### Критерий готовности:
- [ ] Страница `/games/:slug` показывает средний рейтинг и список отзывов
- [ ] Авторизованный пользователь может поставить оценку и написать отзыв
- [ ] Пользователь может редактировать/удалить только свой отзыв
- [ ] Средний рейтинг считается только по не скрытым отзывам
- [ ] `npm test` — все применимые тесты проходят
- [ ] Нет новых lint/typecheck ошибок
