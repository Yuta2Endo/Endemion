# STAGE 01 — AUDIT: Endemion Studio & Community

Дата: 2026-11-04. Репозиторий `Yuta2Endo/Endemion`, ветка `main` (локально совпадает с `origin/main`, последний коммит `2a6e591`).

## 1. Текущее состояние

Сейчас на endemion.online работает **энциклопедия аниме и манги** на данных Shikimori. Её выложили сегодня ночью: `f27a4dd`, затем Universe Explorer `f89c248`. Прежняя платформа чтения (`/reading`, `/catalog`, `/nexus`, `/oracle`) убрана из меню, но её адреса работают. Pulse, Сообщество и Арена есть в меню.

На сервере стоит `f89c248`. В `main` есть ещё два невыложенных коммита: `6c1cd24` (TTL и мониторинг каталога) и `2a6e591` (вход через Google, VK ID и GitHub в Endemion ID; ждёт ключей провайдеров). Любая выкладка редизайна принесёт их с собой.

Исходные проверки на чистом `main`: `npm run lint` — без ошибок, `npm run typecheck` — без ошибок, `npm test` — 99 из 99.

## 2. Стек и архитектура

Код работает без сборки: ES-модули в браузере (`public/assets/*.js`), серверные обработчики в формате Pages Functions (`functions/`). Маршрутизацию делает `src/worker.js` через таблицу `ROUTE_LIST`. Тот же код запускается на Cloudflare Workers с D1, но production — это свой VPS: `server/index.mjs`, Node.js, SQLite через адаптер D1 (`server/d1.mjs`), файлы на диске или в S3 (`server/storage.mjs`). Перед VPS стоит Caddy. Docker Compose поднимает сервисы `app`, `auth` и `caddy`. Миграции применяются при старте после автоматической резервной копии.

HTML страниц собирается на сервере (`functions/_lib/layout.js` → `renderPage`, `siteHeader`, `siteFooter`, `NAV`), данные подгружает скрипт раздела. CSP строгий, без `unsafe-inline`: встроенных скриптов и стилей нет. Кеш сбрасывается через `ASSET_VERSION` и service worker v3.

Endemion ID — отдельный провайдер OpenID Connect в `auth/` (`auth.endemion.online`). Сайт работает с `ENDEMION_ID=1`, Life тоже подключена. В сайте вход реализован в `functions/_lib/endemionId.js`, `functions/api/auth/oidc.js` и `functions/_lib/session.js`. Вторую систему аккаунтов создавать не нужно.

Роли — `user`, `moderator`, `admin` (`functions/_lib/roles.js`). Сервер проверяет роль в каждом обработчике (`requireRole`, `requireUser`), заглушённым пользователям писать нельзя (`mutedProblem`).

Защита уже есть: CSRF через проверку `Origin` в `functions/api/_middleware.js`, только параметризованные запросы, экранирование на сервере и `textContent` в браузере, частота действий (`limits.js`, `rateLimit.js`, таблица `rate_events`), антиспам (ссылки, повторы, одинаковые символы), Turnstile по ключам, журнал `audit_log`.

## 4. Проблемы и противоречия

1. **Главная страница.** Сейчас `/` — главная энциклопедии, выложенной сегодня. ТЗ делает `/` порталом студии с навигацией «Главная, Игры, Сообщество, Разработка, О студии», где энциклопедии нет. Удалять работающую функцию без решения владельца нельзя. Предложение: портал студии на `/`, энциклопедия сохраняет все свои адреса (`/anime`, `/manga`, `/characters` и так далее) и становится одним пунктом меню «Энциклопедия». Главная энциклопедии остаётся доступна по отдельному адресу.
2. **Discord.** ТЗ просит Google, VK и Discord. Владелец 2026-11-04 явно исключил Discord и выбрал GitHub, это реализовано в `2a6e591`. Нужно решение.
3. **Язык.** Сайт полностью на русском, а тексты в ТЗ даны по-английски («Welcome to Endemion», «Explore Games»). Нужно выбрать, на каком языке будет интерфейс.
4. **Данные игр.** Подтверждённые факты есть только про Endemion Life (`G:\III\endemion-life`, life.endemion.online). О TETRUS, LIFE_CITY, OS Developer Simulator и Liforae в коде ничего нет. Придумывать описания, статусы и платформы нельзя. Предложение: в базу заносятся только название и адрес страницы со статусом «не указан», остальное администратор заполняет в админке. На странице незаполненной игры будет честное пустое состояние.
5. **Ограничения `threads`.** Поле `kind` принимает только `discussion` и `theory`, а `title_id` ссылается на тайтлы старой читалки. Категории добавляются новым столбцом `category_id`, существующие ограничения не меняются, пересоздавать таблицу не нужно.
6. **Общая палитра.** Если сменить токены в `base.css`, перекрасится и энциклопедия. Это приемлемо и даже нужно для единого бренда, но все её страницы надо проверить в браузере.

## 5. Риски

- Сервер общий: 1 CPU и 2 ГБ памяти на сайт, Endemion ID и Life. Сборка образа на сервере нагружает Life. Миграции только добавляют таблицы и столбцы (`ALTER TABLE ADD COLUMN`), без пересоздания больших таблиц.
- Перед выкладкой обязательна резервная копия: `server/backup.mjs` пишет копию локально и в S3. Миграция применяется автоматически при старте.
- Вместе с редизайном выедут `6c1cd24` и `2a6e591`. Провайдеры без ключей выключены, поэтому опасного в этом нет, но `auth` нужно пересобрать отдельно (см. память о выкладке Endemion ID).
- Caddyfile менять не нужно: все новые разделы живут в приложении `app`.
- Поисковики уже проиндексировали `/` как энциклопедию. После смены главной нужно обновить `sitemap.xml` и мета-описания.
- Автоматический классификатор часто блокирует SSH и push в `main`. Выкладывать, скорее всего, придётся вам через `!`.

## 5a. Решения владельца (2026-11-04)

- **Главная:** на `/` портал студии. Энциклопедия убрана из меню, но все её адреса (`/anime`, `/manga`, `/characters`, `/people`, `/studios`, `/seasons`, `/rankings`, `/search`, `/mylist`, Universe Explorer) работают. Прежняя главная энциклопедии переезжает на `/encyclopedia`.
- **Соцвход:** Google, VK ID, GitHub и Discord. Discord добавляется в `auth/` по образцу GitHub и включается только при заданных `AUTH_DISCORD_CLIENT_ID` и `AUTH_DISCORD_CLIENT_SECRET`.
- **Язык:** интерфейс на русском, слоганы «ENDEMION — Create. Play. Connect.» и «Welcome to Endemion» на английском.
- **Игры:** в начальные данные — только названия и адреса страниц. Для Endemion Life — факты из её репозитория и ссылка на life.endemion.online. Остальное администратор заполняет в админке.

## 6. План редизайна

Каждый этап — отдельный коммит в ветке `studio-redesign`. После каждого этапа: lint, typecheck, тесты и проверка в браузере через Playwright на 1440×900 и 390×844.

- **STAGE 02, дизайн-система.** Новые токены по ТЗ (`#080A10`, `#11141D`, `#181D29`, `#8B5CF6`, `#6366F1`, `#22D3EE`, `#F8FAFC`, `#94A3B8`) в `base.css` и новый файл `studio.css` с компонентами: кнопки, карточки игр, бейджи статусов, hero, сетки, footer. Новая навигация в `layout.js`, мобильное меню на существующем `menu-toggle`.
- **STAGE 03, главная.** `functions/studio.js` → `/`: Hero с главной игрой из настроек, Featured Game, Our Games, последние темы форума, последние публикации студии, Upcoming. Данные берутся из базы и рендерятся на сервере (SEO), пустые блоки показывают пустые состояния.
- **STAGE 04, игры.** Миграция `0020_studio.sql`: `games` (slug, название, описание, статус `in_development | prototype | released | planned`, платформы, ссылки, известные проблемы, featured, upcoming, позиция, обложка), `game_media` (скриншоты). Страницы `/games` и `/games/:slug`, API `/api/games`.
- **STAGE 05, форум.** `forum_categories` (группа, название, slug, описание, позиция, привязка к игре), столбцы `threads.category_id`, `pinned_at`, `locked_at`. Страницы `/forum`, `/forum/:category`, тема `/community/thread/:id` (адрес не меняется). Цитирование через `> `, закрытая тема не принимает ответов (проверка на сервере). `/users/:username` с перенаправлением со старого `/u/…`, счётчик сообщений и последние сообщения в профиле.
- **STAGE 06, студия.** `studio_posts` (вид `news | devlog | roadmap | update | announcement`, статус `draft | published | archived`, автор, дата, картинка, `game_id`). Страницы `/studio` и `/studio/:slug`. Черновики видят только администраторы, проверка на сервере.
- **STAGE 07, авторизация.** Существующий Endemion ID остаётся как есть. Кнопки «Вход» и «Регистрация» ведут на провайдер, меню профиля показывается после входа. Набор социальных провайдеров — по решению из пункта 4.2.
- **STAGE 08, админка.** Разделы Games, Forum Categories, Studio, Site Settings (`site_settings`: главная игра, соцсети) в существующей `admin.html`. Каждое действие пишется в `audit_log`.
- **STAGE 09–10.** Тесты новых API (права, черновики, закрытые темы, CSRF), Playwright-проверка адаптива, `REDESIGN_FINAL_REPORT.md` и инструкция по выкладке.
