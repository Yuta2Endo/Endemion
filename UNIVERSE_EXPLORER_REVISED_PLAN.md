# Universe Explorer — пересмотренный план

Заменяет `UNIVERSE_EXPLORER_PLAN.md` (canvas-граф, наполнение пяти сериалов администратором). Аудит проекта — `UNIVERSE_EXPLORER_AUDIT.md`.

## Почему план изменён

Первая реализация (локальные коммиты f4f818f, 66daa97, на сервер не попадали) не работала: роутер отвечал 405,
`currentUser` разбирался неверно, граф брал несуществующие поля каталога, таблицы ссылались на `entries`,
анимация не останавливалась, тестов, которые шлют запросы, не было. Canvas-граф дублировал SVG-граф Nexus,
прогресс просмотра дублировал `user_list.progress`, у связей не было источника, а «заполнить 5 сериалов» означало выдумать данные.

## Данные

- **Из каталога, автоматически, у каждого тайтла**: произведение, персонажи (до 24, главные первыми), создатели (до 8),
  студии, связанные произведения (до 12). В базе не хранятся.
- **Вручную, только администратор**: организации, локации, события (`universe_entities`) и связи
  (`universe_relations`: дружба, родство, вражда, соперничество, наставник, принадлежность к организации,
  участие в событии, связь с локацией). У каждой записи обязателен источник (`source_reference`).
- Сэйю в данных произведения каталога нет (они есть только на странице персонажа), поэтому на карту не выводятся.

## Спойлеры

- У ручной записи может быть `episode` — с какого эпизода (главы) она известна зрителю, и `spoiler_level` 0–2.
- Режим «без спойлеров» (по умолчанию): видны записи с `episode <= user_list.progress`, записи без эпизода — только
  со `spoiler_level = 0`. Досмотревшему (статус «Просмотрено») видно всё.
- Режим «полная энциклопедия»: видно всё. Выбор вошедшего хранится в `user_spoiler_settings`, параметр `?mode=` важнее.
- Свой прогресс не заводится: используется список пользователя.

## Хронология

События сортируются по эпизоду (порядок показа) или по `chronology_order` (хронология мира), если он указан.
Участники — персонажи со связью «участие в событии». Без данных — пустое состояние, ничего не придумывается.

## Граф

SVG и та же силовая раскладка, что в Nexus (`public/assets/nexus.js`), раскладка останавливается, когда узлы успокоились.
Карта загружается только при открытии Universe Explorer.

## Статус

1. Миграция 0019, слой данных, API (`functions/_lib/universe.js`, `functions/api/universe.js`) — готово.
2. Админка «Вселенные» (`functions/api/adminUniverse.js`, `public/assets/admin-universe.js`): сущности и связи,
   проверка концов связи, повторов и циклов вложенности, журнал действий — готово.
3. Интерфейс на странице произведения (`public/assets/universe.js`, `universe.css`): кнопка «Путешествие по вселенной»,
   шесть вкладок, переключатель спойлеров, карта, хронология — готово. Скрипт и стили грузятся только при открытии.
4. Тесты: `tests/universe.test.mjs` (11 тестов, запросы через `src/worker.js`, источник каталога подменён).
   Браузерная проверка на локальном сервере: компьютер 1440×900 и телефон 390×844, без ошибок в консоли.

## SEO

Карта не индексируется отдельно: у неё нет своих адресов, состояние (вкладка, фильтры, режим) не попадает в URL,
`/api/` закрыт в robots.txt. Страница произведения индексируется как раньше, с описанием раздела в разметке сервера.

## Наполнение

Записей вселенной на рабочем сайте нет. Пока администратор их не добавит, карта показывает только данные каталога,
вкладки «Организации», «Локации» и «Хронология» — пустое состояние с объяснением.
