## 1. Proposed Architecture

Stage 04 фокусируется на аутентификации и идентификации пользователей, основываясь на существующей архитектуре Endemion:

- **Сервер:** Cloudflare Workers / Node.js (`functions/studio.js`, `functions/site.js`, `functions/api/auth/`)
- **Клиент:** Чистые ES-модули (`public/assets/`)
- **База:** SQLite / D1 (существующие таблицы `users`, `sessions`, `user_profiles`, `endemion_id` связанные таблицы)
- **Внешний сервис:** Endemion ID (auth.endemion.online) — OIDC провайдер
- **Стиль:** Существующие CSS токены Stage 01 (`base.css`, `studio.css`)

Маршруты, которые могут быть затражены:
- `/auth` — вход, регистрация (существуют, могут требовать улучшений UX)
- `/profile` — личный кабинет (существует, может требовать улучшений)
- `/api/auth/*` — API аутентификации (существуют)
- Возможно: `/api/users/:username/follow` — подписки (существуют)

## 4. Architecture Limitations

| Ограничение | Описание | Рекомендация |
|-------------|----------|--------------|
| Нет серверной сборки | Все ассеты отдаются как есть, нет оптимизации размеров | Оставить как есть, добавить сжатие на уровне Caddy |
| Один файл CSS на все стили | `studio.css` растёт с каждым этапом | Разделить на модульные файлы при необходимости |
| Нет клиентского роутинга | Все навигация через серверный рендеринг | Оставить как есть для SEO |
| Зависимость от внешнего auth-провайдера | Тесты не могут быть запущены без auth.endemion.online | Добавить моки для тестов |
| Нет wishlist/библиотеки для игр | Только для удалённых разделов (аниме/манга) | Добавить таблицу `game_library` в миграции |

## 7. Proposed Implementation Plan (Stage 04)

### Шаг 1 — Аудит аутентификации (1 день)
- Проверить существующие `/api/auth/*` эндпоинты
- Проверить интеграцию с Endemion ID (OIDC)
- Проверить страницы `/auth` и `/profile`
- Выявить пробелы в UX

### Шаг 2 — Wishlist для игр (2–3 дня)
- Добавить таблицу `game_library` (user_id, game_id, created_at)
- Добавить API эндпоинты: `POST /api/users/:username/library`, `DELETE /api/users/:username/library/:game_id`
- Добавить кнопку "В избранное" на страницах игр (только для авторизованных)
- Добавить раздел "Избранное" в профиль пользователя

### Шаг 3 — Улучшения UX аутентификации (2–3 дня)
- Визуальная доработка страниц `/auth` и `/reset`
- Улучшение обработки ошибок входа/регистрации
- Исправление видимости кнопки регистрации на мобильных

### Шаг 4 — Проверка (1–2 дня)
- `npm run lint`, `npm run typecheck`, `npm test`
- Проверка аутентификации, wishlist, профиля
- Проверка локализации (RU/EN)
