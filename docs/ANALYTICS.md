# Аналитика: что считаем и как включить цели

Метрика на сайте уже стоит: счётчик подключается из `public/assets/app.js`, ID берётся из переменной `YANDEX_METRIKA_ID` и отдаётся клиенту через `/api/config`. Счётчик грузится **только после согласия на cookie** — до нажатия «Принять» никаких запросов к Яндексу нет, поэтому и цели не отправляются.

## Какие цели отправляет сайт

Код вызывает `goal(имя)` из `public/assets/app.js` — это обёртка над `ym(id, "reachGoal", имя)`. Если счётчика нет (гость не дал согласие), вызов молча ничего не делает и не мешает действию.

| Цель | Когда срабатывает | Где вызывается |
|---|---|---|
| `register` | успешная регистрация | `public/assets/auth.js` |
| `login` | успешный вход | `public/assets/auth.js` |
| `thread_create` | создана тема форума | `public/assets/community.js`, `public/assets/forum-category.js` |
| `comment` | отправлен комментарий или ответ | `public/assets/comments.js` |
| `library_add` | игра добавлена в избранное | `public/assets/game-page.js` |

Имена фиксированные: менять их в коде и в панели нужно одновременно, иначе цель перестанет считаться.

## Как включить (панель владельца)

1. Открыть [metrika.yandex.ru](https://metrika.yandex.ru) → нужный счётчик → **Цели**.
2. Создать цель типа **JavaScript-событие**, идентификатор — ровно одно из имён выше (`register`, `login`, `thread_create`, `comment`, `library_add`). Название можно любое, например «Регистрация».
3. Повторить для остальных целей.
4. Через сутки посмотреть отчёт **Конверсии** — там будет видно, сколько посетителей доходит до каждого шага.

Пока цели не созданы, сайт всё равно отправляет события: Метрика их принимает, но в отчётах они не появятся, пока в панели нет цели с таким идентификатором.

## Как проверить, что работает

1. Открыть сайт, согласиться на cookie.
2. DevTools → Network → фильтр `reachGoal`.
3. Выполнить действие (например, отправить комментарий).
4. Должен появиться запрос к `mc.yandex.ru` с именем цели в параметрах.

Если запроса нет — проверить, что счётчик загрузился (`window.ym` определён) и что согласие дано.

## Чего мы не отправляем

В целях нет персональных данных: только имя события. Тексты постов, адреса почты и имена пользователей в Метрику не уходят. Вебвизор выключен намеренно — он записывает ввод в формы.

## Cloudflare Web Analytics

Если задан `WEB_ANALYTICS_TOKEN`, дополнительно грузится счётчик Cloudflare: он без cookie, поэтому работает и без согласия. Он показывает посещения и Core Web Vitals, но не цели — для воронки нужна Метрика.
