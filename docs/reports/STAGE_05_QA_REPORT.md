## 1. QA Scope

Проверена функция Stage 05 — система оценок и отзывов к играм:

- Игровая страница без отзывов (пустое состояние).
- Игровая страница с несколькими отзывами.
- Расчёт средней оценки и количества отзывов.
- Отзыв только с оценкой (без текста).
- Отзыв с текстом.
- Отзыв со спойлером и взаимодействие «показать спойлер».
- Редактирование своего отзыва.
- Удаление своего отзыва.
- Поведение гостя (чтение без авторизации, запрет на создание).
- Локализация RU/EN.
- Десктопная и мобильная вёрстка (CSS адаптив).
- Ошибки API (400, 401, 403, 404, 409).
- Состояния загрузки/успеха/ошибки на клиенте.
- Не регрессия функционала избранных игр (Stage 04).

## 8. Manual QA Checklist (если браузеры станут доступны)

1. Открыть `/games/:slug` без отзывов — пустое состояние, сводка отсутствует, гостю показана кнопка «Войти».
2. Открыть `/games/:slug` с отзывами — сводка (средняя оценка, количество), список отзывов newest-first, спойлер скрыт.
3. Нажать «Показать спойлер» — текст появляется, кнопка удаляется, работает с клавиатуры (Enter).
4. Авторизованный пользователь — форма оценки 1–10, optional текст, чекбокс спойлера, кнопка сохранить.
5. Score-only — отправка без текста успешна.
6. Повторная отправка — 409 «уже оставили отзыв», форма переходит в режим редактирования.
7. Редактирование — изменение оценки/текста сохраняется.
8. Удаление — отзыв исчезает, сводка пересчитывается.
9. Гость не может отправить отзыв (401).
10. Переключение языка (RU/EN) — строки интерфейса переводятся.
11. Мобильная вёрстка (<=680px) — секция отзывов адаптируется.
12. Вкладка избранного в профиле — не регрессировала.
