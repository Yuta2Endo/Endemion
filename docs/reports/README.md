# Отчёты по этапам

Здесь лежат исторические отчёты о разработке сайта: аудиты, планы, отчёты о реализации, QA и деплое (этапы 01–10, аудит редизайна, проверка подключения Telegram-бота). Они описывают, **как** сайт дошёл до текущего состояния, и не обновляются.

Актуальные документы — на уровень выше, в `docs/`:

- `ENDEMION_ECOSYSTEM_ARCHITECTURE.md` — устройство сайта, Endemion ID и Life;
- `ENDEMION_DEPLOYMENT.md` — деплой и откат на своём сервере;
- `ENDEMION_AUTH_SETUP.md` — настройка Endemion ID;
- `ENDEMION_ACCOUNT_MIGRATION.md` — перенос аккаунтов на единый вход;
- `ENDEMION_SECURITY.md` — модель безопасности;
- `SITE_IMPROVEMENT_PLAN.md` — текущий план улучшений и его статус.

Если ищете, почему что-то сделано именно так, начинайте с отчётов этапов: в них зафиксированы решения владельца и найденные ограничения. Если ищете, как это работает сейчас, — смотрите `docs/` и код.
