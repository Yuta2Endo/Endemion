# STAGE 03–04 — HOMEPAGE и GAMES

Ветка `studio-redesign`.

## Что сделано

- **Миграция `0020_studio.sql`** только добавляет таблицы и столбцы: `games`, `game_media`, `studio_posts`, `forum_categories`, `site_settings`, а в `threads` — столбцы `category_id`, `pinned_at`, `locked_at`. Существующие обсуждения переносятся в категорию «Общее обсуждение». Slug проверяется на уровне базы (латиница, цифры, дефис), сайт игры принимается только с `https://`.
- **Начальные данные.** Для Endemion Life — факты из README её репозитория (браузерный симулятор жизни с элементами RPG, статус «В разработке», платформа «Браузер», ссылка https://life.endemion.online). TETRUS, LIFE_CITY, OS Developer Simulator и Liforae заведены только с названием и адресом страницы, статус «не указан». Категории форума созданы по ТЗ, у каждой игры своя категория.
- **`/` — главная портала** (`functions/studio.js`): Hero с главной игрой из `site_settings.featured_game`, Featured Game (статус, платформы, «Играть», «Об игре», «Обсуждение»), Our Games, последние темы форума, новости разработки и Upcoming Projects. Блок Upcoming показывается, только если администратор отметил хотя бы одну игру как будущую.
- **`/games` и `/games/:slug`**: hero, описание, скриншоты, статус, платформы, последние обновления, Devlog, Roadmap, известные проблемы, обсуждения на форуме и ссылка на сайт игры. Ссылок на магазины приложений нет. Черновик игры (`published = 0`) видят только администраторы, это проверяется на сервере.
- **`/studio`, `/studio/:slug`, `/about`, `/terms`** — основа для STAGE 06. Публикации появятся, когда их создадут в админке.
- **Картинки** — `/media/games/:id/cover`, `/media/games/:id/shots/:mediaId`, `/media/posts/:id` (`functions/media.js`). Картинка черновика публикации не отдаётся.
- **Заглушки** вместо обложек подписаны «Обложка скоро появится» и озвучиваются скринридером как «Обложка … ещё не загружена».
- **SEO**: canonical, Open Graph, JSON-LD (`Organization`, `VideoGame`, `BlogPosting`). В `sitemap.xml` попадают игры и публикации, черновики — нет.
- Текст из базы всегда экранируется. Разметка описаний ограничена: абзацы, `## ` заголовки и `- ` списки, HTML не проходит.
