# STAGE_01_DESIGN_SYSTEM — Endemion

**Статус:** Черновик реализации (реализовано в CSS, см. STAGE_01_IMPLEMENTATION_REPORT.md)  
**Источник:** существующий проект `G:\III\Project\Endemion` ( base.css, ui.css, studio.css, layout.js, i18n.js )  
**Целевой визуал:** Premium dark, минимализм, фиолетово-синие акценты, сильная типографика, просторная вёрстка, адаптив.

---

## 1. Design Philosophy

Endemion — независимая игровая студия и сообщество. Визуальный язык должен быть:
- **Премиальным:** тёмный фон, глубокие поверхности, сдержанный блеск акцентов.
- **Минималистичным:** нет декоративных элементов, не несущих функции.
- **Технологичным:** чёткая иерархия, остаточные эффекты свечения, плавные переходы.
- **Лаконичным:** типографика несёт основную нагрузку, избыточных скруглений и градиентов нет.
- **Отличительным:** фирменный градиент логотипа (индиго → фиолетовый → пурпурный), буква "E" как marcas.

Не используется: неон, избыточный стеклоэффект, AI-эстетика, перегруженные интерфейсы, фейковый контент.

## 5. Layout Rules

- **Container:** центрирован, `width: min(1240px, calc(100% - 40px))`,margin `0 auto`.
- **Grid:** CSS Grid с `auto-fill` / `auto-fit` и `minmax()` для карточек (игр, постов, кадров).
- **Split:** `grid-template-columns: minmax(0, 1fr) 340px` для основной колонки + боковой панели (складывается в одну на <=1080px).
- **Hero:** `.studio-hero` с фоновой обложкой и двуколоночным_inner (текст + карточка featured), на <=900px — одна колонка.
- **Навигация:** шапка `position: sticky`, высота 72px, на мобильном — гамбургер-меню (выдвигается под шапкой).
- **Подвал:** 4 колонки (о студии, разделы, проекты, документы), на <=900px — 2 колонки, на <=680px — 1.
- **Разделы (section):** `.section-head` с eyebrow + h2 + текст + действия справа.
- **Пустые состояния:** `.empty-card` / `.state` с иконкой, заголовком, текстом и опциональной кнопкой действия.
- **Скелетоны:** `.skeleton` с анимацией shimmer, отключаются при `prefers-reduced-motion: reduce`.

## 8. Animation Guidelines

- Плавные переходы: `0.2s ease` для цветов/фонов/границ, `0.25s ease` для карточек, `0.4s ease` для изображений внутри карточек.
- Вход элементов: `@keyframes rise` (opacity + translateY), задержка 0.08–0.16s для последовательности.
- Скелетоны: `@keyframes shimmer` 1.4s linear infinite.
- Спиннер: `@keyframes spin` 0.8s linear infinite.
- Кнопки: `transform: translateY(-1px)` при hover.
- **Отключение:** `@media (prefers-reduced-motion: reduce)` — `animation: none !important`, `transition: none !important`, `scroll-behavior: auto`.
- Избегать: избыточной анимации, мигания, автовоспроизведения медиа.

## 9. Accessibility Requirements (WCAG 2.2 AA)

- `skip-link` на каждой странице.
- `:focus-visible` с чёткой обводкой 2px `--accent-light`, offset 3px, radius 6px.
- Все интерактивные элементы имеют чёткое состояние фокуса.
- `aria-current="page"` для активной навигации.
- `aria-label` на иконковых кнопках (поиск, колокольчик, меню, язык).
- `aria-expanded`, `aria-controls` для гамбургер-меню.
- `aria-hidden="true"` на декоративных иконках.
- `visually-hidden` для текстовых меток, замещаемых иконками.
- `<label>` с `for`/`id` для всех полей формы.
- `required`, `minlength`, `maxlength`, `pattern` для валидации на уровне HTML.
- `dialog` элемент для модальных окон, возвращение фокуса при закрытии (реализовано в JS `openDialog`).
- `lang` на `<html>`, два языка (ru/en) через cookie и `Accept-Language`.
- Цветовой контраст основного текста на фоне соответствует ≥ 4.5:1.
- `prefers-reduced-motion` respected.
