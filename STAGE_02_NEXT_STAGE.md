## 1. Proposed Architecture

Stage 03 развивает существующую архитектуру портала Endemion Studio без замены фреймворка:

- **Сервер:** Cloudflare Workers / Node.js (`functions/studio.js`, `functions/site.js`)
- **Клиент:** Чистые ES-модули (`public/assets/`)
- **База:** SQLite / D1 (существующие таблицы `games`, `studio_posts`, `game_media`)
- **Стиль:** Существующие CSS токены Stage 01 (`base.css`, `studio.css`)

Маршруты, которые будут затрагиты:
- `/games` — каталог игр (уже существует, требует улучшения)
- `/games/:slug` — страница игры (уже существует, требует улучшения)
- Новые маршруты по мере необходимости (например, фильтрация, сравнение)

## 3. Required Features

### 3.1 Projects Hub (`/games`)
- Улучшенная сетка игр с превью обложек
- Фильтрация по статусу (в разработке, прототип, вышедшая, запланирована)
- Фильтрация по платформам
- Поиск по названию (интеграция с существующим `/api/search`)
- Сортировка (по дате, алфавиту, позиции)
- Пустое состояние при отсутствии результатов

### 3.2 Product Pages (`/games/:slug`)
- Премиальный hero с обложкой игры
- Подробное описание из базы (`description`, `tagline`)
- Скриншоты из `game_media`
- Roadmap (существующие публикации с `kind: "roadmap"`)
- Новости и обновления игры (`kind: "update", "news"`)
- Devlog игры (`kind: "devlog"`)
- Связанная категория форума для обсуждения
- CTA: играть (если `websiteUrl`), обсудить, добавить в желаемое

### 3.3 Data Integrity
- Только реальные данные из базы — без выдуманных игр, рейтингов, статистики
- Статусы только из существующих: `in_development`, `prototype`, `released`, `planned`
- Изображения только из загруженных ассетов или подписанных заглушек

## 4. Implementation Plan

### Шаг 1 — Аудит существующих страниц игр (1 день)
- Проверить `/games` и `/games/:slug` на соответствие дизайн-системе Stage 01
- Выявить несоответствия в верстке и типографике

### Шаг 2 — Улучшение каталога игр `/games` (2–3 дня)
- Добавить фильтры по статусу и платформам (CSS + серверная фильтрация)
- Улучшить карточки игр (более выразительное медиа, четкая типографика)
- Добавить пустое состояние и состояние загрузки

### Шаг 3 — Улучшение страниц игр `/games/:slug` (3–5 дней)
- Премиальный hero с обложкой и мета-информацией
- Секции: описание, скриншоты, roadmap, новости, devlog, комьюнити
- CTA-кнопки: играть, обсудить, подробнее
- Structured data (VideoGame) уже существует — сохранить

### Шаг 4 — Проверка (1–2 дня)
- `npm run lint`, `npm run typecheck`, `npm test`
- Проверка адаптивности, локализации, доступности

## 5. Risks

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Регрессия существующих страниц игр | Средняя | Средняя | Добавлять новые CSS-классы, не удалять старые |
| Выдуманный контент (рейтинги, статистика) | Низкая | Высокая | Использовать только данные из БД |
